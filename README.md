# 두 줄 노래방 자막 만들기

일본어 노래 가사로 **두 줄 노래방 ASS 자막**을 만드는 웹사이트입니다.
일본어 원문·한글 발음·한국어 뜻·후리가나를 위/아래 줄에 번갈아 배치하고, 다음 줄을 미리 보여 줍니다.
모든 처리는 브라우저 안에서 이루어지며 서버가 필요 없습니다. (자동 후리가나만 외부 변환 서비스를 사용합니다.)

## 사용 순서

1. **가사 넣기**: 원문 → 한글 발음 → 뜻 순서로 붙여넣거나, SRT·ASS·프로젝트 파일을 불러옵니다.
2. **영상·음악 열기**: 불러오면 미리보기와 파형(웨이브폼)이 표시됩니다.
3. **줄 시간 찍기**: 「처음 마킹」 탭에서 노래를 들으며 각 줄 시작에 `M`을 누릅니다.
4. **음절 다듬기**: 「음절 타이밍」 탭에서 「음절 탭 시작」을 누르고, 음절이 바뀔 때마다 `K`를 누릅니다.
   파형의 노란 점선(음절 경계)이나 줄 경계를 마우스로 끌어 미세하게 조절할 수 있습니다.
5. **ASS 저장**: 「완성도 검사」로 빠진 곳을 확인한 뒤 「ASS 다운로드」를 누릅니다.

### 파형 조작

| 동작 | 결과 |
| --- | --- |
| 클릭 | 재생 위치 이동 |
| 줄 이름(색 띠) 클릭 | 그 줄 선택 |
| 줄 경계·음절 경계 끌기 | 시간 수정 (Ctrl+Z로 되돌리기) |
| 빈 곳 끌기 / 마우스 휠 | 좌우 이동 |
| Ctrl + 휠, −/+ 버튼 | 확대·축소 |

### 단축키 (기본값, 바꿀 수 있음)

`M` 시작 찍기 · `E` 끝 찍기 · `K` 음절 탭 · `Space` 재생/일시정지 · `Ctrl+Z` / `Ctrl+Y` 되돌리기/다시하기

## ASS 출력

- 음절 타이밍이 있는 줄은 음절마다 `{\kf}` 태그가 들어가 노래에 맞춰 칠해집니다. 없는 줄은 줄 전체가 같은 속도로 칠해집니다.
- 후리가나도 해당 한자가 불리는 시점에 칠해집니다.
- 내보낸 ASS를 다시 불러오면 후리가나 표기와 음절 타이밍이 그대로 복원됩니다 (`KaraokeSource` Comment 줄에 원본이 저장됨).

## 영상에 자막 입히기 (Windows)

`tools/자막입히기.bat`에 영상(또는 음악)과 ASS 파일을 함께 끌어다 놓으면 같은 폴더에 `영상이름_자막.mp4`가 만들어집니다.
사이트의 「검사 · 내보내기」 패널에서도 두 파일을 받을 수 있습니다.

- ffmpeg(libass)로 입히므로 Aegisub·영상 플레이어에서 보이는 모습과 같습니다.
- ffmpeg가 없으면 처음 실행할 때 `winget`으로 설치할지 물어봅니다.
- NVIDIA·Intel·AMD 그래픽카드 인코더가 있으면 자동으로 사용하고, 실패하면 CPU(libx264)로 다시 시도합니다.
- 음악 파일만 놓으면 검은 1920×1080 화면에, 그림 파일을 함께 놓으면 그 그림 위에 자막을 입힙니다.
- ASS에 쓰인 폰트를 찾아 함께 넘겨 주므로, 사용자 계정에만 설치한 폰트도 적용됩니다.
- 화면이 뜨지 않고 바로 닫히면 `tools` 폴더에서 PowerShell을 열고 `.\burn-subtitles.ps1 영상.mp4 자막.ass`로 실행해 메시지를 확인하세요.

## 지원 브라우저

Chrome·Edge 최신 버전을 권장합니다. 작업 폴더 연결, 프로젝트 파일 덮어쓰기, PC 폰트 읽기는 Chrome·Edge에서만 동작합니다.
`.mkv` 등 일부 형식은 브라우저가 소리를 읽지 못해 파형이 표시되지 않을 수 있습니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조, 예제 프로젝트 데이터, 폰트 목록 |
| `style.css` | 디자인 |
| `karaoke-text.js` | 후리가나 표기 해석, 음절 자동 나누기, 음절 시간 계산 (화면과 무관한 함수) |
| `waveform.js` | 파형 타임라인 그리기와 마우스 조작 |
| `app.js` | 나머지 화면 동작, 미리보기, ASS 만들기·불러오기 |
| `tools/` | 영상에 자막을 입히는 Windows 스크립트 (`자막입히기.bat`, `burn-subtitles.ps1`) |

## 개발 메모

`index.html?selftest`로 열면 내장 자체 검사가 실행되고 결과가 `<html data-selftest="pass|fail">`에 기록됩니다.
자체 검사 중에는 브라우저에 저장된 작업을 건드리지 않습니다.
